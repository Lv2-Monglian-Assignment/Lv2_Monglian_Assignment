# 프로젝트 1 보고서 — 비전 기반 객체 추적 시스템

## 문제 3 — 객체 중심 기반 추적 제어

### 3-1. Kp 2종 × 3회 계단 응답 비교 ([#9](https://github.com/Lv2-Monglian-Assignment/Lv2_Monglian_Assignment/issues/9))

#### 구현 내용
- 성취도: 제어 담당 체크리스트 9 (Kp 2종 각 3회 시험, 원본 CSV와 비교 결과로 특성 설명)
- 추적 제어 노드 이전 단계로, OpenCR의 위치 P 제어에서 Kp 두 값의 반응 속도·오버슈트·정착을 팬·틸트 모터별로 비교해 추적 Kp 후보를 정하는 근거로 사용
- 펌웨어: `opencr_position_p` (모터 속도 모드 + OpenCR 위치 P, `command = clamp(Kp × 오차, ±속도 상한)`, 데드밴드 0.2°)

#### 실행 조건
| 항목 | 값 |
|---|---|
| 모터 | 팬 DYNAMIXEL XM430-W350-T ID 11, 틸트 XM430-W350-T ID 12 (1 Mbps, Protocol 2.0) |
| Kp 2종 | 2.0, 3.0 [1/s] (각도 오차 → 각속도 명령) |
| 속도 상한 | 120°/s |
| 제어 주기 · 로그 주기 | 100 Hz · 10 Hz |
| 시작 자세 | 명령 시점 위치를 0°로 두고 2초 대기 후 계단 이동 |
| 목표 각도 | 팬 +90°, 틸트 ±40° (틸트 기구 간섭 한계) |
| 반복 | 모터·Kp별 3회, 총 12회 (실패 회차 없음) |
| 명령 | 시리얼 모니터에서 `s <Kp> 120 <목표각>` → 정착 후 `x` (정지·토크 OFF) |

- 틸트는 run 1이 +40°, run 2·3이 −40°입니다. 분석할 때 위치·목표·명령의 부호를 뒤집어 양수로 맞췄습니다.
- Kp 외 설정(속도 상한·데드밴드·부하·장착 상태)은 바꾸지 않았습니다.

산식 (계단 명령 시점을 0 s로 맞추고 10 ms 간격으로 선형 보간한 곡선 기준):
- 오버슈트 = 최대 위치 − 목표
- 상승 시간 = 목표의 90% 도달 시각 − 10% 도달 시각
- 1° 이내 진입 = 이후 계속 |위치 − 목표| < 1°가 되는 첫 시각
- 포화 = 속도 명령 |u| ≥ 119°/s인 로그 샘플 수 × 0.1 s

#### 해석
- **반복성**: 같은 Kp의 3회 결과가 거의 같습니다 (오버슈트 표준편차 틸트 0.11° 이하, 팬 0.50° 이하, 상승 시간 차이 0.03 s 이하). 틸트는 +40°와 −40° 회차의 차이도 작아 방향에 따른 영향은 크지 않았습니다.
- **틸트**: Kp 3은 상승이 약 40% 빠르고(1.04 → 0.64 s) 1° 이내 진입도 0.24 s 빠르지만, 3회 모두 약 3.2° 넘어갔습니다. Kp 2는 명령이 상한에 닿지 않고(최대 79.7°/s) 오버슈트 없이 다가가며, 목표 근처에서 데드밴드 안쪽에 0.2~0.3° 오차를 남기고 멈춘 회차가 있습니다.
- **팬**: 목표가 90°로 커서 두 Kp 모두 명령이 120°/s 상한에 걸렸습니다. 그래서 상승 시간 차이는 0.14 s로 작고, Kp 3은 약 27° 넘어간 뒤 되돌아와 1° 이내 진입이 오히려 1.0 s 느렸습니다.
- **오버슈트 원인 (가설)**: 명령은 120°/s인데 측정 속도는 그보다 낮아(틸트 약 60°/s), 모터가 명령을 늦게 따라갑니다. 감속 명령이 나올 때 실제 속도가 아직 크기 때문에 넘어가는 것으로 봅니다. 큰 Kp일수록 상한 근처 명령이 오래 유지되어 영향이 커집니다.
- **선택**: 두 모터 모두 **Kp 2.0**이 오버슈트가 작고 정착이 안정적입니다. 틸트는 ±40°에서 기구 간섭이 생기므로, 끝 근처에서 3° 넘어가는 Kp 3은 피합니다.

#### 심화
- 수행하지 않음. (데드밴드·필터 변경 비교는 추적 시험 이후 검토)

#### 한계
- 이 시험의 Kp는 **각도 루프** 기준([1/s])이라, 영상 오차 ex 기준 추적 Kp와 단위가 다릅니다. 추적 Kp 2종 × 3회 시험(왼쪽 → 중앙 → 오른쪽 → 중앙, 오차·명령·상태 CSV)은 추적 제어 노드 구현 후 별도로 수행합니다.
- 로그 주기가 10 Hz라 시간 지표는 0.1 s 해상도의 샘플을 보간한 값입니다.
- 오버슈트 원인은 측정 속도와 명령의 차이로 세운 가설이며, 모터 가속 설정을 바꿔 확인하지는 않았습니다.
