# 통합 작업 작성·실행 도구 기록

## 기여 구분

| 항목 | 실제 기여와 실행 범위 |
|---|---|
| 팀 저장소 구조 | 패키지·폴더 구조와 노드별 설정 파일 구성을 만들었다(#11, #28~#33). 원본 코드 분류는 [인지 기록](../perception/AI_CONTRIBUTIONS.md)의 팀 구조 배치와 같은 작업이다. |
| 공용 설정 | 설정을 노드별 파일과 공용 값(`/**`)으로 나눴다. 검출 값은 장비 실측(10-05·10-06) 설정을 옮겼다. |
| launch 구성 | 장비 시험에서 launch 인자가 무시되는 문제(dry_run인데 실제 포트를 엶)를 찾고, 설정 폴더 인자와 덮어쓰기 방식을 정해 고쳤다(#40). |
| bag 기록·재처리 | 기록·재처리·분석 스크립트를 만들었다(#41). Lyrical에서 기록이 멈추는 문제와 metrics.csv 손상을 시험으로 찾아 고쳤다(#43, #53). |
| 실행 프로그램·메뉴 | 문제·도전별 시험 프로그램, 통합 메뉴, 부팅 자동 실행의 동작을 정하고 구현했다(#42, #53). 결과 확인·판정은 직접 했다. |
| 재현 확인 | 다른 팀원이 README만 보고 실행한 기록은 team.md에 남긴다. 작성자의 실행을 팀원 재현으로 표기하지 않는다. |
