# 제어 작업 작성·실행 도구 기록

## 기여 구분

| 항목 | 실제 기여와 실행 범위 |
|---|---|
| 제공 예제 | `opencr_position_p.ino`(3강 P 제어 예제, `s <Kp> <속도> <목표각>` 계단 입력)는 외부 제공 자료다. 작성 기여로 계산하지 않는다. |
| Kp 계단 응답 | 팬·틸트 Kp 5종 × 3회를 실제 모터에서 실행하고, 결과로 팬 2.0·틸트 2.5와 각도 단위 [1/s]를 정했다. |
| OpenCR 펌웨어 | 예제를 바탕으로 요구사항을 정해 만들었다(#14). 장비 시험에서 찾은 문제마다 정책을 정해 고쳤다: 토크 유지·기준 자세(#38), 연속 3회 실패 시 FAULT·자동 복구·바퀴 수 유지(#54). |
| 추적 제어 노드 | 각도 오차 환산, 속도 상한 120°/s, 각도 한계 처리, 보드 FAULT 기록 규칙을 정하고 구현했다(#38, #52, #54). |
| 실측 설정값 | 모터 ID·통신 속도·방향 부호·회전 범위·기준 자세는 장비에서 직접 확인했다. |
| 시험 도구 | 시험 항목·판정 기준과 메뉴 동작을 정하고 `scripts/test/`·`assignment/`에 구현했다(#38, #42, #53). 결과 확인·판정은 직접 했다. |
| 외부 리뷰 | 자체 검토를 팀원의 PR 승인으로 표기하지 않는다. 리뷰 링크는 team.md에 기록한다. |
