# 추적 Kp의 단위와 환산 근거

report.md 문제 3(P 추적)과 README 5절에 옮겨 적을 원본 기록이다. 결정일 2026-10-06.

## 1. 결정
- 추적 Kp는 report 3-1(#9) 계단 응답 시험의 **각도 루프 Kp를 그대로** 쓴다: 팬 **2.0**, 틸트 **2.5** [1/s].
- 제어 노드가 화면 오차를 각도로 바꾼 뒤 Kp를 곱한다.

```
각도 오차 [deg] = atan(e × tan(시야각/2))          e = ex(팬) 또는 ey(틸트), −1 ~ +1
명령 [deg/s]    = clamp(direction × Kp × 각도 오차, −속도 상한, +속도 상한)
```

## 2. 왜 계단 응답의 Kp를 그대로 쓸 수 있나
- 계단 응답 시험의 루프: `명령 = Kp × (목표 각도 − 모터 각도)`. 이 시험으로 Kp를 정했다.
- 추적 루프: 카메라가 모터 축에 달려 있어서, 화면 중심에서 목표까지의 각도가 곧 "목표 방향 − 카메라(모터) 방향"이다.
- 그래서 같은 종류의 오차를 같은 모터로 줄이는 루프이고, Kp의 단위와 의미가 같다.
- 다른 점은 영상 경로의 지연이다(아래 4절).

## 3. 정규화 오차를 각도로 바꾸는 식
- 핀홀 카메라에서 화면 중심으로부터의 픽셀 거리는 tan(각도)에 비례한다: `u = fx × tan(θ)`.
- 정규화 오차는 `ex = u / (W/2)`이고, 화면 끝(`ex = 1`)의 각도가 시야각/2이므로 `tan(θ) = ex × tan(시야각/2)`, 즉 `θ = atan(ex × tan(시야각/2))`.

| 목표 위치 | ex | 각도 오차 | 팬 명령 (Kp 2.0) |
|---|---|---|---|
| 오른쪽 10° | 0.334 | 10.0° | −20.0°/s |
| 모의 입력 x = +0.4 | 0.400 | 11.94° | −23.87°/s |
| 화면 오른쪽 끝 | 1.000 | 27.85° | −55.7°/s |

(팬 direction = −1: 오른쪽 목표에 음수 속도 = 카메라가 오른쪽으로 돈다. 2026-10-06 방향 시험.)

## 4. 이전 환산값(60.5 / 56.8)과의 차이
- 처음에는 화면 중앙 근처의 기울기로 근사했다: `atan(x) ≈ x` → 각도 ≈ ex × 320/fx rad = ex × 30.26°.
  - 팬 2.0 × 30.26 = **60.5** [°/s per 1.0 정규화 오차], 틸트 2.5 × 22.70 = **56.8**.
- 이 근사는 중앙에서는 같지만 화면 끝으로 갈수록 명령이 커진다: 팬 +8.6 % (60.5 대 55.7°/s), 틸트 +5 %.
- 그래서 2026-10-06에 atan 식으로 바꾸고, 설정에는 팀이 정한 Kp(2.0, 2.5)를 그대로 둔다.
- 참고: 다른 통합본(final_20261006)의 Kp 20 / 15 [°/s per 1.0]는 각도 Kp로 약 0.66 / 0.66에 해당한다.

## 5. 영상 지연과 안정성 (추정, 실측으로 확인할 것)
- 지연 추정: 영상 stamp → `/target` 발행 약 78 ms(2026-10-05 실측) + 제어 주기 20 ms + 브리지·시리얼·모터 ≈ **0.13 s**.
- P 루프의 교차 주파수는 약 Kp [rad/s]이므로, 지연에 의한 위상 지연 ≈ Kp × 지연: 팬 2.0 × 0.13 = 0.26 rad ≈ **15°**, 틸트 2.5 × 0.13 = 0.33 rad ≈ **19°**.
- 모터 응답을 뺀 위상 여유가 크므로 진동 가능성은 낮다고 본다. 모터 동특성(가속 프로파일)은 넣지 않은 계산이다.
- 확인: 발제 문제 3의 Kp 2종 × 3회 시험(왼쪽 3 s → 중앙 3 s → 오른쪽 3 s → 중앙 3 s)으로 실제 흔들림·응답을 비교한다. 비교할 두 번째 Kp는 시험 전에 정해 Issue에 기록한다.
