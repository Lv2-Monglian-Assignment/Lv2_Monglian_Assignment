# 인지 실제 프레임 평가와 결과 제출 준비

## 문제와 목표

세 장면 사진·ROS 인터페이스 확인 이후 독립 대상 30프레임·없음 10프레임 평가와 팀 제출 증빙이 남아 있다. 각 프레임의 정답 근거·원본·설정·검출 결과를 보존하고 오검출·미검출을 설명한다.

## 수행 목록

- [x] 기존 HSV·윤곽·ROS 구현과 실측 근거를 정리한다.
- [x] Pi에서 동일 검출 코드를 실행해 큰 영상 전송을 줄이고 PC 결과 수신을 확인한다.
- [x] 실제 프레임 수집·고정 설정 평가·출처 검증 도구를 준비한다.
- [ ] 물체 배치·정답을 확인하고 독립 30·10프레임을 수집·평가한다.
- [ ] 오검출·미검출과 실험 한계를 보고서에 기록한다.
- [ ] 팀 저장소 PR·리뷰·team.md 증빙을 연결한다.

## 완료 기준

40개 실제 프레임의 판정표·원본/마스크/검출·설정/소스 사본·평가 보고서와 실제 Issue·PR·리뷰 근거를 확보한다. 합성 검사나 메시지 수신 개수를 독립 영상 평가로 계산하지 않는다.

현재는 로컬 초안이며 Issue URL은 아직 없다.
