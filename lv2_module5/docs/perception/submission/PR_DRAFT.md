# 인지 실제 프레임 평가 도구와 Pi 검출 실행 기록

기존 한 장 검출만으로는 독립 대상 30·없음 10프레임의 출처와 정답 대조를 관리하기 어려웠다. 순번별 실제 PNG·원본 hash·header·장면 정답 근거를 저장하는 도구와 고정 설정으로 40개를 검증·평가하는 도구를 추가했다. 동일 검출 코드의 실행 위치를 Pi로 옮긴 조건과 PC `/target` 수신 근거도 기록했다.

## 변경

- 실제 프레임 수집과 출처 보호: 기존 폴더 보존·source stamp 중복 방지·장면 라벨 근거 기록.
- 고정 설정 평가: 원본·소스 hash, 30·10개 조건과 영상 형식 검증, 프레임별 이미지·CSV·JSON 저장.
- 인지 계획·보고서·팀 문서와 작성·실행 도구 기여 정리.

## 검증

- 기존 검출 합성 검사 7개 통과.
- 평가 출처 보호 검사 8개 통과.
- 같은 실제 사진의 PC OpenCV 4.6·Pi 4.10 마스크와 좌표 일치.
- Pi 검출 → PC `/target` 10초 관측: 297개·약 29.88Hz, 실제 발행 QoS와 유효 값 확인.
- 독립 30·10프레임 정확도 평가: 실제 후보 30장 확보, 목표 정답 확인·없음 10장 대기로 아직 미완료. 결과를 확보한 뒤 이 설명에 반영한다.

## 한계

짧은 관측은 장기 안정성이나 시스템 전체 추적 성능을 증명하지 않는다. 현재 팀 저장소·실제 PR·팀원 리뷰는 아직 연결하지 않았다. 게시 전 최종 파일 범위·평가 결과·검증 로그와 이 설명을 다시 대조한다.
