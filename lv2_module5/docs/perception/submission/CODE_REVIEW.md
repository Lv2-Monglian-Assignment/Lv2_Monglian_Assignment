# 인지 변경 자체 코드 검토

## 검토 범위

실제 프레임 수집·별도 라벨 사본·고정 설정 평가·출처 보호 검사와 Pi 실행 구성 기록을 검토한다. 기존 검출 함수·ROS 노드·HSV YAML은 변경하지 않았다. 이 기록은 자체 검토이며 팀원의 실제 PR 리뷰나 승인 증빙이 아니다.

## 확인 결과

- 기존 출력 폴더·라벨 파일을 덮어쓰지 않는다.
- 촬영 source stamp가 증가하는 서로 다른 프레임만 저장하고 원본 PNG hash를 남긴다.
- 정답 미확인 후보는 unlabelled/null로 기록하고 정답 평가에서 제외한다.
- 라벨 확정 시 원본 JSON을 보존하고 별도 파일에 근거와 원본 hash를 남긴다.
- 평가에서 실제 30·10개 조건·원본/소스 hash·장면 라벨·영상 형식·source stamp 중복을 검증한다.
- 라벨 사본이 원본 프레임의 stamp·사진 hash 등 증거를 바꾸면 평가를 거부한다.
- PNG·원본 사진 모음 저장 실패와 ROS 정리 오류를 성공으로 처리하지 않는다.
- 출력은 프레임별 원본·마스크·검출과 CSV·JSON·소스/설정 사본이다.
- 대상 유무 정확도와 중심 위치 정확도·전체 추적 성능을 구별한다.

## 검증 근거

- 기존 검출 합성 검사 7개 통과.
- 출처 보호 검사 8개 통과.
- 합성 40개 입력의 평가 CLI·CSV/이미지 출력·기존 출력 보존 확인: [소프트웨어 통합 검사](../../../results/logs/perception/autonomous-runtime-001/software-integration-check.json).
- 실제 수집 도구 2프레임 저장·hash·null 라벨 확인: [실제 수집 도구 점검](../../../results/logs/perception/collector-runtime-check-001/dataset.json).
- 실제 후보 30프레임 저장·hash 확인: [후보 검토 상태](../../../results/logs/perception/evaluation-candidate-review-001/review-state.json).
- 같은 실제 사진의 PC·Pi 마스크·좌표 일치 및 Pi 출력 PC 수신은 [인지 보고서](../report.md)에 연결한다.

## 남은 확인

실제 추적 목표 지정·물체 제거와 원본 정답 검토, 40프레임 최종 평가, 팀 저장소 반영과 외부 리뷰는 남아 있다. 라벨 근거 문자열 자체가 물체 배치를 증명하는 것은 아니므로 원본 검토와 실제 확인을 별도 증거로 남긴다. 10초 수신 관측은 장기 안정성 증명이 아니다.
